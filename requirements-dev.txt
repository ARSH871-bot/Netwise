# Netwise development-only dependencies
#
# Nothing here is needed to RUN Netwise, and nothing in analysis/, ai/ or web/
# imports any of it. The product and the pytest suite both work without this
# file installed. It exists so that `pip install -r requirements.txt` stays
# small enough to be the one command a new person runs.
#
# Install on top of the main requirements:
#
#     pip install -r requirements.txt -r requirements-dev.txt

# Drives a real browser, for checking the dashboard actually behaves rather
# than only that its JavaScript parses. Earned its place verifying US-10's
# auto-refresh: it selected a fixture in the file input and screenshotted the
# loading state WHILE Batfish was still running, which no amount of reading
# the code would have confirmed.
#
# Needs a one-off browser download after install:
#
#     python -m playwright install chromium     (~115 MB)
#
# Note the pytest suite does NOT use it today; the checks so far have been
# standalone scripts. That is also why CI does not install this file -- see
# .github/workflows/tests.yml, which installs requirements.txt only.
