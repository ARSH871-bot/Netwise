Netwise

Network configuration analysis — runs entirely offline

Analyse a config

Config files (.cfg, .conf, .txt), up to 2 MB — Cisco IOS, Cisco NX-OS, Arista EOS and Juniper JunOS, or a PF Sense config.xml export. Nothing leaves this machine.

A JSON policy of your own rules (#87). Checks that can read it will assert your rules instead of our built-in examples, and every finding says which of the two it used.

Scan results

Three separate counts, not one total. Problems found and checked, nothing found are both results — the check ran either way. Could not check is not a pass: those checks did not run, so nothing is known about what they cover.

Ask a question

Questions are answered by running a real check against the uploaded config. The question understood is always shown back, so you can see what was actually asked. Anything that cannot be translated is refused rather than guessed.

Propose a change

Describe one change in plain English and Netwise will write the config line, simulate it, and warn you if it opens something. Nothing is ever applied to a device — the change is tested against a throwaway copy.
